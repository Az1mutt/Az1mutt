## Featured projects

### 🧠 [Personal AI Brain](https://github.com/Az1mutt/personal-ai-brain)

A local-first agent platform for coordinating projects, tools, and future autonomous workflows.

The project currently includes durable Project OS state, explicit agent contracts and permission boundaries, a read-only Core Agent, a bounded control plane, and a remote work execution path with persistent task state, duplicate/replay protection, cancellation, isolation, auditability, automated tests, and CI.

The design deliberately separates **reasoning capability from execution permission**: autonomy is added only after the underlying boundaries are explicit and testable.

### 🍳 [Recipe Intelligence System](https://github.com/Az1mutt/recipe-intelligence-system)

A PostgreSQL/Supabase-based recipe intelligence data product focused on structured culinary knowledge, provenance, ingestion, classification, and personal preference modeling.

Its guarded-agent workflow separates **Discovery → Resolution → Classification → QA/Review → deterministic Promotion**, with evidence-backed decisions, idempotency, escalation rules, and constrained write authority. A real creator-scale pilot has been used to validate the workflow before broader automation.

### 🏠 [Homelab Infrastructure](https://github.com/Az1mutt/homelab-infrastructure)

A dedicated Ubuntu Server environment used for self-hosting, infrastructure learning, and running personal engineering projects.

The repository documents a real migration from a laptop-hosted stack to a dedicated server, including Docker services, storage migration, rollback strategy, recovery checks, monitoring, and application-level validation.
